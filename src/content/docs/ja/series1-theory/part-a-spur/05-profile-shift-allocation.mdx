## 5.1 実務的背景と物理的本質：転位総和決定後に潜む致命的設計の罠

機械設計および自動車駆動系・減速機のCAE構造解析と射出成形設計に20年以上携わってきた経験において、若手設計者が最も陥りやすい致命的な誤解が「転位の総和（$\Sigma x = x_1 + x_2$）さえ決まれば転位設計は完了した」と思い込むことです。

ケーシングの要求中心距離（運転中心距離 $a'$）を満足させるためにインボリュート超越方程式を解き、所要の転位総量 $\Sigma x = +0.30$ を算出したと仮定しましょう。対象はモジュール $m = 1.0\,\text{mm}$、小歯数ピニオン $z_1 = 11$、大歯車 $z_2 = 41$ の減速機ギアセットです。ここで最も本質的な工学的課題が浮上します。この $+0.30$ をピニオンと大歯車へどのように配分すべきでしょうか？

実務の現場で頻発する三大失敗パターンは次の通りです：

1. **無転位放置（$x_1 = 0.00, x_2 = +0.30$）**: ピニオンの転位をゼロのまま放置し、大歯車にのみ正転位を配分する手法です。標準圧力角 $\alpha_0 = 20^\circ$ における限界歯数は $z_{\min} = 17.1$ です。わずか11歯のピニオンを無転位でホブ盤加工すると、創成工具の歯先が歯元インボリュート有効部を深くえぐり取ってしまいます。危険断面の歯元厚さはわずか $1.55\,\text{mm}$ にまでくびれ、激しい応力集中を招きます。その結果、定格トルクの30%程度の軽負荷運転であっても、わずか数十時間で歯元疲労亀裂が発生し、歯が根元からへし折れる致命的破損（Tooth Breakage）を招きます。
2. **均等配分の過ち（$x_1 = +0.15, x_2 = +0.15$）**: 50/50の機械的均等配分では、ピニオンのアンダーカット限界所要転位量（$x_{1,\min} = +0.357$）に到底届きません。依然としてアンダーカットが残留し、小歯数ピニオンと大歯車の曲げ強度不均衡は解消されません。
3. **過大転位による尖頭化（$x_1 = +0.65, x_2 = -0.35$）**: アンダーカットを恐れるあまりピニオンに過剰な正転位を与えると、歯先円厚さ（$s_{a1}$）が $0.20m$ を割り込み、刃物のように尖頭化（Cresting）します。浸炭焼入れ時に歯先角部へ熱応力が集中して微小クラックが生じ、組立て後の初期噛合い衝撃で歯先が欠損（Chipping）する事態に至ります。

転位係数の配分は単なる算術的な割り算ではなく、**歯元曲げ疲労強度、歯面ピッチング寿命、歯先尖頭化限界、そして噛合い率の連続性**を同時に調和させる高度な多目的最適化問題です。

## 5.2 幾何学と微分積分に基づく正統的数学的導出：6大最適配分基準

DIN 3992およびISO 21771規格に立脚し、転位配分において遵守すべき**6大最適配分基準**を体系的に定立します。

### 第1基準. 最小アンダーカット防止配分法

創成工具の歯先線が基礎円との接点 $N$ の内側へ侵入しないための最小所要転位係数は以下の閉じた式で導出されます：

$$x_1 \ge x_{\min} = 1.0 - \frac{z_1 \sin^2\alpha_0}{2}$$

標準圧力角 $\alpha_0 = 20^\circ$（$\sin 20^\circ = 0.342020$）を代入すると：

$$x_{1,\min} = 1.0 - \frac{11 \times 0.116978}{2} = 1.0 - 0.643378 = +0.356622 \approx +0.357$$

したがって、$z_1 = 11$ のピニオンにおいてアンダーカットを完全排除するには $x_1 \ge +0.357$ の確保が絶対条件です。本ベンチマーク設計では十分な安全マージンを考慮し、$x_1 = +0.450$ を採用します。

### 第2基準. 固定中心距離満足配分法（無バックラッシ噛合い条件）

規定された運転中心距離 $a'$ に標準モジュール歯車対を適合させるインボリュート超越関係式です：

$$\text{inv}\,\alpha_w = \text{inv}\,\alpha_0 + 2\frac{x_\Sigma}{z_1 + z_2}\tan\alpha_0 = \text{inv}\,\alpha_0 + 2\frac{x_1 + x_2}{z_1 + z_2}\tan\alpha_0$$

基礎円ピッチの不変性より、運転中心距離 $a'$ は厳密に求まります：

$$a' = a \frac{\cos\alpha_0}{\cos\alpha_w} = \frac{m(z_1 + z_2)}{2} \frac{\cos\alpha_0}{\cos\alpha_w}$$

中心距離変更係数 $y$ は次のように定義されます：

$$y = \frac{a' - a}{m}$$

標準頂げき $c = 0.25 m$ を厳格に保持するための歯先短縮係数 $k$ は以下の通りです：

$$k = x_\Sigma - y = (x_1 + x_2) - \frac{a' - a}{m}$$

これに伴う歯先円直径（$d_a$）および歯底円直径（$d_f$）は以下の式で計算されます：

$$d_{a1} = m(z_1 + 2 + 2x_1 - 2k), \quad d_{a2} = m(z_2 + 2 + 2x_2 - 2k)
d_{f1} = m(z_1 - 2.5 + 2x_1), \quad d_{f2} = m(z_2 - 2.5 + 2x_2)$$

噛合い時の実頂げき $c$ は厳格な不変性を示します：

$$c = a' - r_{a1} - r_{f2} = a' - \frac{d_{a1} + d_{f2}}{2} \equiv 0.25 m$$

### 第3基準. 歯先円厚さ限界配分法（尖頭化防止）

正転位が増加するにつれて歯先円上の円周歯厚 $s_a$ は急激に減少します。ISOおよびDIN規格では、焼割れ防止およびチッピング防止のため $s_a \ge 0.25 m$（浸炭熱処理品では $\ge 0.30 m$）が義務付けられています：

$$s_{ai} = 2 r_{ai} \left( \frac{s_i}{2 r_i} + \text{inv}\,\alpha_0 - \text{inv}\,\alpha_{ai} \right) \ge 0.25 m, \quad \cos\alpha_{ai} = \frac{r_{bi}}{r_{ai}}$$

ここで $s_i = m(\pi/2 + 2 x_i \tan\alpha_0)$ は基準ピッチ円歯厚です。

### 第4基準. 噛合い率極大化配分法

滑らかで衝撃のない動力伝達を担保するため、正面噛合い率 $\epsilon_\alpha$ の最小許容限界は $\epsilon_\alpha \ge 1.20$（高精度伝動では $\ge 1.30$）に設定されます：

$$\epsilon_\alpha = \frac{g_\alpha}{p_b} = \frac{\sqrt{r_{a1}^2 - r_{b1}^2} + \sqrt{r_{a2}^2 - r_{b2}^2} - a' \sin\alpha_w}{\pi m \cos\alpha_0} \ge 1.20$$

転位総和が増加して運転圧力角 $\alpha_w$ が広がるほど有効噛合い長さ $g_\alpha$ は短縮するため、$\epsilon_\alpha = 1.200$ の境界線は設計許容領域の上限を決定します。

### 第5基準. 等曲げ強さ配分法

ISO 6336-3（Method B）に基づく歯元曲げ応力 $\sigma_F$ は、歯形係数 $Y_F$ と応力修正係数 $Y_S$ に比例します：

$$\sigma_{F1} = \frac{F_t}{b m} Y_{F1} Y_{S1} Y_\beta Y_B Y_T \approx \sigma_{F2} = \frac{F_t}{b m} Y_{F2} Y_{S2} Y_\beta Y_B Y_T \implies \frac{\sigma_{F1}}{\sigma_{F2}} \equiv 1.0$$

11歯の小径ピニオンは幾何学的に大歯車よりも応力集中が著しく厳しくなります。ピニオンに大きな正転位（$x_1 = +0.45$）を与えて歯元を太くし、大歯車に適正な負転位（$x_2 = -0.15$）を配分することで、歯形係数を均衡化（$Y_{F1} \approx 2.628, Y_{F2} \approx 2.588$）させ、曲げ応力（$\sigma_{F1} = 144.23\,\text{MPa}$ vs $\sigma_{F2} = 147.52\,\text{MPa}$）および安全率を $1:1$ の比率（$\sigma_{F1}/\sigma_{F2} = 0.978$）に一致させます。

### 第6基準. 最大比滑り平衡配分法

歯面の摩耗およびピッチング（表面疲労損傷）を最小化するため、ピニオン歯元噛合い開始点（点A、SAP）での比滑り $k_{1,\max}$ と大歯車歯元噛合い終了点（点E、EAP）での比滑り $k_{2,\max}$ を均等に平衡させます：

$$k_{1,\max} = 1 - \frac{\omega_2 \rho_{a2}}{\omega_1 \rho_{f1}} = 1 - \frac{\omega_1 \rho_{a1}}{\omega_2 \rho_{f2}} = k_{2,\max}$$

このとき作用線上の任意の接触点において、以下の比滑り恒等式が厳密に成立します：

$$(1 - k_1)(1 - k_2) \equiv 1.0$$

## 5.5 JIS B 1702 / KS B 0002 歯車図面要目表実務

## 5.6 2軸分力および軸受反力動力学解析

転位総和（$x_\Sigma = +0.30$）の適用により運転圧力角が基準値（$20.00^\circ$）から $\alpha_w = 21.66^\circ$ へ増大することに伴い、軸受へ作用する半径方向分離力 $F_r$ が変化します：

$$F_t = \frac{2000 T}{d_{w1}} = \frac{2000 \times 1.0\,\text{N}\cdot\text{m}}{11.122\,\text{mm}} = 179.82\,\text{N}$$

半径方向分離力 $F_r$ は運転圧力角の正接に比例します：

$$F_r = F_t \tan\alpha_w = 179.82 \times \tan(21.6609^\circ) = 179.82 \times 0.39716 = 71.42\,\text{N}$$

基準圧力角運転時（$F_{r0} = 179.82 \times \tan 20^\circ = 65.45\,\text{N}$）と比較すると、分離力は約 $9.1\%$ 増加します。しかし、歯元曲げ耐力が $55\%$ 向上する絶大なメリットは、わずか $9\%$ の軸受反力増大を圧倒的に凌駕しており、非対称正転位配分こそが減速機システム全体において真の最適解であることを力学的に立証しています。
